# Data-Driven Solutions and Discoveries in Mechanics Using Physics-Informed Neural Networks

## Machine Learning Mini Project

This project reproduces experiments from the paper  
**"Data Driven Solutions and Discoveries in Mechanics Using Physics Informed Neural Network"**  
by Qi Zhang, Yilin Chen, and Ziyi Yang.

The project uses Physics-Informed Neural Networks (PINNs) to solve and analyse three mechanics problems:

1. 1D Consolidation
2. 2D Steady-State Heat Conduction
3. Inverse Parameter Identification for a Damped Dynamic System

We also implement a hard boundary-condition extension for the 2D heat-conduction problem.
